# КлиматКомфорт39 — сайт и маркетинговый пакет

Готовый статический прототип для `climatcomfort39.ru`: премиальная подача инженерных систем для дизайнеров, проектных организаций и конечных владельцев в Калининграде и области.

## Быстрый старт

Откройте `index.html` в браузере или запустите из папки проекта:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Затем откройте `http://localhost:8080`. Для хостинга достаточно загрузить содержимое этой папки на обычный статический хостинг / сервер домена.

## Важное перед публикацией на реальном домене

1. **Добавьте реальные контакты:** телефон, мессенджеры, e‑mail, адрес/режим, ссылки на карты и реквизиты. Они сознательно не выдуманы в прототипе.
2. **Подключите формы:** сейчас `data-demo-form` показывает сценарий успеха и не отправляет персональные данные. Подключите CRM, корпоративную почту или Telegram‑бот.
3. **Замените шаблон политики:** заполните `privacy.html` фактическими данными оператора и согласуйте с юристом.
4. **Проверьте цены и характеристики:** ориентиры в `services.html` и отчёте — гипотезы на основе публичного исследования, не публичная оферта. Обновите по закупке, марже, загрузке и договорной модели.
5. **Проверьте бренд‑допуски:** AI‑визуалы — концептуальные, а не официальные фотографии Hisense / Valtec / Zehnder / BlauShop. Для карточек реального оборудования используйте согласованные материалы поставщика.
6. **Поставьте аналитику:** Яндекс Метрика, цели форм, UTM, коллтрекинг/CRM‑воронку и consent banner при их использовании.
7. **Добавьте реальные кейсы:** только с письменными разрешениями на фото, планы и отзывы.

## Технические детали

* Каждая HTML-страница теперь **самодостаточна**: CSS, JavaScript, SVG-иконки и использованные изображения встроены в сам файл через inline-стили и data URI. Поэтому дизайн корректно отображается и в файловом preview, который не загружает относительные CSS/JS/изображения.
* Адаптивная версия для мобильных устройств, контролируемый размер SVG-иконок, цветовые секции, интерактивное мобильное меню, FAQ и демонстрационные формы.
* В папке `scripts/` сохранён `rebuild_self_contained_site.py` — исходник новой самодостаточной сборки. После изменения визуалов его можно повторно запустить.
* Видео H.264 совместимо с современными браузерами; на главной есть визуальная карточка-превью, а готовый MP4 лежит в `media/`.
